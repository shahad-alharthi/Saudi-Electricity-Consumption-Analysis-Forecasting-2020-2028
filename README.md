#⚡️Saudi-Electricity-Consumption-Analysis-Forecasting-2020-2028

An end-to-end data science and forecasting solution combining SQLite, Python, ML ( Multiple Linear Regression ), and Power BI to project electricity consumption per customer across Saudi Arabia's regions through 2028.

---

## 🗂️ Data Sources

Data was gathered and engineered from trusted official sources:
* **STATS:** General Authority for Statistics.
* **SERA:** Saudi Electricity Regulatory Authority
* **KAPSARC:** King Abdullah Petroleum Studies and Research Center.
* **Open-Meteo:** Historical weather and temperature logs (average and maximum).

---

## 🛠️ Tech Stack

* Data Ingestion & Cleaning: Python (Pandas, NumPy)
* Bullet Database & ETL: SQLite3, SQL (Multi-table JOINs)
* Machine Learning: Scikit-Learn (Multiple Linear Regression)
* Data Visualisation: Power BI, Power Query, DAX
* Reporting & Export: OpenPyXL / Pandas ExcelWriter

---

## 🚀📊 Key Tasks & Impact

* **Task 1 (Data ETL & Cleaning):** Imported, validated, and cleaned multi-source data (consumption, population, and temperature), checking for nulls and duplicates.
* **Task 2 (SQL Engineering):** Stored datasets in a local `SQLite` database and built advanced `JOIN` queries to merge historical data (2020–2024).
* **Task 3 (Machine Learning Forecasting):** Developed and trained a **Multiple Linear Regression** model correlating consumption with demographic growth and temperature variables, applying statistical guardrails to ensure a realistic upward trajectory through 2028.
* **Task 4 (Power BI Dashboard):** Designed an interactive executive dashboard displaying core KPIs, regional drivers, and multi-year trend analysis.
